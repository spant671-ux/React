## 🚀 Getting Started

To run any of the project folders locally:

### 1. Vite Project (`01_vitereact`)
```bash
cd 01_vitereact
npm install
npm run dev
```

### 2. Basic React Project (`01_basicreact`)
```bash
cd 01_basicreact
npm install
npm start
```
